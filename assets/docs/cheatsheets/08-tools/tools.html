The quant's toolbox

Bloomberg Terminal, Power BI, Git, Power Automate: what they're actually used for day to day.

Basic reflexes Bloomberg: the <GO> key confirms any command  |  Git: a commit is a snapshot of your code at a point in time

Bloomberg Terminal

  • Industry reference for market data, analytics and professional messaging.
  • Key functions: PORT (portfolio), WEI (indices), FX, HP (price history).
  • Excel add-in (BQL/API) to pull data directly into your models.

Power BI

  • Builds interactive dashboards from multiple data sources.
  • The DAX language enables custom calculations and measures.
  • The standard for risk, performance and activity reporting.

Git

  • Version control system for code: history, branches, and the ability to roll back.
  • A commit is a snapshot, a branch is a parallel line of work.
  • Essential as soon as a pricer or model is shared between multiple people.

Power Automate

  • Automates repetitive tasks across applications (email, Excel, SharePoint...).
  • Works through triggers and actions, with no coding required.
  • Useful for automating recurring reports or follow-ups.

Who uses what?

Trader / Sales Bloomberg Terminal for pricing, execution and market communication.
Reporting analyst Power BI to turn raw data into readable dashboards.
Quant developer Git to version and collaborate on pricing or risk model code.
Process automation Power Automate to make repetitive manual tasks reliable without heavy development.

Key takeaways

  1. Bloomberg remains unmatched for real-time market data, but Power BI takes over as soon as custom reporting is needed.
  2. Git isn't just for developers: as soon as an Excel/Python model is shared across a team, versioning avoids the "final_v2_really_final.xlsx" problem.
  3. Power Automate quickly pays back its learning curve on any repetitive task taking more than a few minutes a week.

Real-world examples

PORT on Bloomberg

A portfolio manager uses the PORT function to analyze a portfolio's sector exposure and risk at a glance.

PnL dashboard

A Power BI dashboard aggregates daily trading data to track PnL by desk in near real time.

Versioning a pricer

A quant team uses Git branches to develop a new pricing feature without breaking the version in production.

Automated weekly report

A Power Automate flow sends an auto-generated Excel summary every Monday from a shared SharePoint site.

Quick glossary

API Interface that lets two pieces of software exchange data automatically.
Excel add-in Extension that pulls Bloomberg data directly into Excel.
DAX Formula language used in Power BI to create measures and calculations.
Repository / branch Code storage and a parallel line of development in Git.
Workflow Automated chain of actions triggered by an event in Power Automate.
Commit Recording a set of code changes in Git's history.
