La boîte à outils du quant

Bloomberg Terminal, Power BI, Git, Power Automate : à quoi ça sert vraiment au quotidien.

Réflexes de base Bloomberg : la touche <GO> valide toute commande  |  Git : un commit est une photo de ton code à un instant T

Bloomberg Terminal

  • Référence du secteur pour les données de marché, l'analytique et la messagerie professionnelle.
  • Fonctions clés : PORT (portefeuille), WEI (indices), FX, HP (historique de prix).
  • Excel add-in (BQL/API) pour extraire des données directement dans ses modèles.

Power BI

  • Construit des tableaux de bord interactifs à partir de multiples sources de données.
  • Le langage DAX permet des calculs et mesures personnalisés.
  • Standard en reporting risque, performance et suivi d'activité.

Git

  • Système de versioning du code : historique, branches, retours en arrière possibles.
  • Un commit = un instantané, une branche = une ligne de travail parallèle.
  • Indispensable dès qu'un pricer ou un modèle est partagé entre plusieurs personnes.

Power Automate

  • Automatise des tâches répétitives entre applications (email, Excel, SharePoint...).
  • Fonctionne par déclencheurs (trigger) et actions, sans coder.
  • Utile pour automatiser des reportings récurrents ou des relances.

Qui utilise quoi ?

Trader / Sales Bloomberg Terminal pour le pricing, l'exécution et la communication marché.
Analyste reporting Power BI pour transformer des données brutes en tableaux de bord lisibles.
Développeur quant Git pour versionner et collaborer sur le code d'un pricer ou d'un modèle de risque.
Automatisation de process Power Automate pour fiabiliser des tâches manuelles répétitives sans développement lourd.

À retenir

  1. Bloomberg reste incontournable pour la donnée de marché en temps réel, mais Power BI prend le relais dès qu'il s'agit de reporting personnalisé.
  2. Git n'est pas réservé aux développeurs : dès qu'un modèle Excel/Python est partagé en équipe, le versioning évite les "final_v2_vraiment_final.xlsx".
  3. Power Automate rentabilise vite son coût d'apprentissage sur toute tâche répétitive de plus de quelques minutes par semaine.

Exemples concrets

PORT sur Bloomberg

Un gérant utilise la fonction PORT pour analyser l'exposition sectorielle et le risque d'un portefeuille en un coup d'œil.

Dashboard PnL

Un dashboard Power BI agrège les données de trading quotidiennes pour suivre le PnL par desk en temps quasi réel.

Versionner un pricer

Une équipe quant utilise des branches Git pour développer une nouvelle fonctionnalité de pricing sans casser la version en production.

Reporting hebdo automatisé

Un flow Power Automate envoie chaque lundi un résumé Excel généré automatiquement à partir d'un SharePoint partagé.

Lexique express

API Interface permettant à deux logiciels d'échanger des données automatiquement.
Excel add-in Extension permettant d'extraire des données Bloomberg directement dans Excel.
DAX Langage de formules utilisé dans Power BI pour créer des mesures et calculs.
Repository / branche Dépôt de code et ligne de développement parallèle dans Git.
Workflow Enchaînement automatisé d'actions déclenché par un événement dans Power Automate.
Commit Enregistrement d'un ensemble de modifications de code dans l'historique Git.
